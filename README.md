# My Programming Tasks

دي مجموعة من التاسكات والمشاريع البسيطة اللي كنت بعملها وأنا بتعلم البرمجة.

كنت بطبق فيها الحاجات اللي بتعلمها في HTML و CSS و JavaScript، وكل Task كان بيساعدني أفهم حاجة جديدة وأتدرب عليها عمليًا.

من الحاجات اللي طبقتها:

* HTML و CSS
* Forms
* Animations
* Grid
* Hover Effects
* JavaScript
* Calculator
* Rating System
* Weather App
* Hotel Price Calculator
* Time Table
* Filtering

المشاريع دي جزء من فترة تعلمي وتطوري في البرمجة، وبستمر في إضافة مشاريع وتاسكات جديدة كل ما أتعلم حاجات أكتر.
